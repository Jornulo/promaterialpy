# Datasets included in promaterialpy

This file documents the origin and license of each dataset included
in the **promaterialpy** Python package.

---

## commercial_regulations

- **Internal name:** `commercial_regulations`  
- **Original filename:** `promaterial_commercial_regulations.csv`  
- **Source:** Kaggle  
- **URL:**  https://www.kaggle.com/datasets/purushottamnawale/materials
- **License:** MIT
- **Description:**  
  It contains detailed specifications, heat treatments, and standards (ANSI, DIN, ISO, GOST).

## commercial_properties

- **Internal name:** `commercial_properties`  
- **Original filename:** `promaterial_commercial_properties.csv`  
- **Source:** Kaggle  
- **URL:**  https://www.kaggle.com/datasets/purushottamnawale/materials
- **License:** MIT
- **Description:**  
  It contains the fundamental elastic properties (including Poisson's ratio and density) for direct mechanical calculations.

## youngs_modulus

- **Internal name:** `youngs_modulus`  
- **Original filename:** `youngs_modulus.csv`  
- **Source:** Kaggle  
- **URL:** https://www.kaggle.com/datasets/kanchana1990/youngs-modulus-of-metals?select=youngs_modulus.csv   
- **License:** Open Data Commons Attribution License (ODC-By) v1.0  
- **Description:**  
  Young's Modulus of Metals from Soft to Stiff: A Complete Dataset of Young's Modulus for 50 Metals
